# Visual P1 — paquete de transferencia

Este paquete es una biblioteca de referencias visuales y especificación, **no una integración del juego**.

- Los PNG de `candidates/` no están aprobados para producción.
- La [Art Bible v1.1](ArtBible_v1.1_Vera_Taller.md) registra el canon definitivo de Vera: 2,5 cabezas y rasgos ADN v1.1, incluido el scrunchie con pictograma de bicicleta; sin aros ni anteojos.
- Está aprobada la dirección editorial de **viviendas fotorrealistas ficticias**. El maestro de cada vivienda será vertical **4:5**. Desktop usará la misma escena extendida lateralmente o un encuadre equivalente, conservando todas las pistas.
- H01 requiere una **bomba de bicicleta visible**, además de las demás pistas acordadas.
- Los talleres B2.0 permanecen pendientes de validación 390px/200%, y no deben sustituir `public/homes/h01.svg`.
- No sobreescribir ni modificar mecánica, puntuación, preguntas, tests o GitHub Pages en esta ingesta.
- `manifest.json` lista orígenes y SHA256.

La aprobación editorial de estas decisiones **no aprueba ningún archivo candidato**. El siguiente gate es la revisión y aprobación explícita de los activos finales con los [criterios de aceptación](ACCEPTANCE_CRITERIA.md). El [plan técnico de integración](../../superpowers/plans/2026-10-13-wholiveshere-visual-p1.md) se conserva para después de ese gate.
