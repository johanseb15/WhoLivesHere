# ADEL ART-H06-H10-P1

## Objetivo
Elevar progresivamente la calidad artistica de H06-H10
al nivel aprobado de H01-H05 sin modificar GitHub main.

## Alcance
H06 Alma: observatorio junto a la ventana.
H07 Bruno: mesa de cartas y postales.
H08 Cora: observacion de mareas.
H09 Dani: laboratorio de sabores.
H10 Elena: reparacion textil e hilos.

## Direccion artistica
- Conservar el sistema cromatico y editorial de WhoLivesHere.
- Crear ambientes narrativos con composicion espacial propia.
- Evitar tableros repetitivos de iconos.
- Incorporar pistas visuales verificables para cada pregunta.
- No escribir las soluciones directamente en las ilustraciones.
- Priorizar calidad y legibilidad a 320 y 390 px.
- Conservar la interfaz React y CSS aprobada.
- No generar retratos sin una decision artistica explicita.

## Revelacion
- Evitar duplicar la misma escena en dos paneles.
- Mostrar una recompensa visual coherente sin inventar un retrato.
- Mantener identidad, cita, puntaje y explicaciones accesibles.

## Metodo ADEL
1. Revisar ilustraciones existentes y preguntas.
2. Preparar propuestas visuales para aprobacion.
3. Implementar un hogar piloto antes de los restantes.
4. Ejecutar TDD y verificar pistas y accesibilidad.
5. Generar capturas comparables a 320, 390, 768 y 1440 px.
6. Registrar decisiones, pendientes y evidencias.

## Gates
- Identidad visual preservada.
- Cada escena tiene composicion y pistas diferenciadas.
- Ninguna pista esencial queda oculta.
- Sin regresiones funcionales ni responsive.
- Vitest, typecheck y build aprobados.
- Playwright revisado sin aprobar snapshots automaticamente.
- Sin commit, merge, push ni publicacion sin autorizacion.

## Fuera de alcance
H11-H20, nuevo contenido narrativo, rediseño global,
cambios en scoring y publicacion en GitHub Pages.
