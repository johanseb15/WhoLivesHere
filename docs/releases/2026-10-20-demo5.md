# Demo publica WhoLivesHere — 5 hogares

Base `main` 133e46d, sin H06-H20. Mantiene 5 hogares, 15 preguntas y maxima puntuacion 30. Integra fotos realistas JPG y cinco retratos 3D desde la rama `adel/art-h06-h10-p1` (85239a4). Los SVG anteriores se mantienen en el repositorio solo como recurso tecnico.

## Gates antes de promocion a main
- Ejecutar `pnpm install --frozen-lockfile`, `pnpm run test:run`, `pnpm run typecheck`, `pnpm run build`.
- Validar visualmente los 5 hogares y revelaciones en movil 320/390 px y escritorio, pistas, imagen ampliada, navegacion, reinicio y resultado 30/30.
- Obtener aprobacion explicita del fundador antes de merge y publicar.
- Confirmar Pages en `https://johanseb15.github.io/WhoLivesHere/` y rutas con prefijo `/WhoLivesHere/`.
- Si falta alguna pista visual o se observa desvio de estilo, bloquear la promocion a main.
